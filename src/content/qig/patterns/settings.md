## Best practices

- Choose good defaults, and expose only what people really change.
- Lay settings out as [grouped lists](/design/qig/grouped-lists): rows grouped by topic, with a short header and an explanation under the group when it helps.
- Switches apply immediately. There is no Save button for settings.
- Follow the device’s appearance, motion and contrast settings instead of duplicating them.
- Settings for a task live with the task, for example in that screen’s “More” menu, not only on a global settings page.
- A row with a trailing chevron opens more settings; a row with a switch changes something.
