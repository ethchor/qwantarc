| The screen is about…                                  | Use                                                      |
| ----------------------------------------------------- | -------------------------------------------------------- |
| A list of records people search, filter and act on    | [Page anatomy](/design/qig/page-anatomy) with a table    |
| Reviewing records one after another                    | [Master and detail](/design/qig/master-and-detail)       |
| An area of a product with several screens              | [Hub](/design/qig/hubs)                                  |
| Fast, repeated entry                                   | [Keyboard-first work](/design/qig/keyboard-first-work)   |
| Preferences                                            | [Settings](/design/qig/settings)                         |
| A hierarchy of nested records                          | [Hierarchies](/design/qig/hierarchies)                   |
| Adding or editing one record                           | [Editing records](/design/qig/editing-records)           |

## Best practices

- Pick the layout before designing any detail. Mixing two layouts on one screen usually means it should be two screens.
- Reuse a layout people already know from elsewhere in the product, even when a custom one looks slightly better on its own.
