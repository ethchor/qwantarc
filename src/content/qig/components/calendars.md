## When to use

Scheduling, rosters and side panels that browse by day.

## Best practices

- Today reads as tinted; the selection uses the accent fill.
- Arrow keys move between days; Return selects.

## Avoid

A plain date in a form. Use a [date picker](/design/qig/date-pickers).
