## When to use

- Next to the commands they trigger: in menus, tooltips and a shortcuts list.
- For commands people repeat all day.

## Best practices

- Define a shortcut once with a platform-neutral modifier and display it in each platform’s own notation.
- Every shortcut also has a visible control. Shortcuts are accelerators, never the only way.
- Keep a list of all shortcuts one keystroke away.

## Avoid

Overriding the standard shortcuts: copy, paste, undo, find and print.
