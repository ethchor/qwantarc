## When to use

Product-wide navigation and frequent commands, for people who prefer the keyboard.

## Best practices

- Results are grouped (Go To, Actions, Learn) and keyboard driven: up and down to move, Return to open, Escape to close.
- Show each result’s shortcut when it has one.
- An empty search shows suggestions; no results says so and offers help.
